# Have I Been Pwned API v3: Documentation Sample

Independent documentation for the free, key-less endpoints of the [Have I Been Pwned](https://haveibeenpwned.com) API v3, written and verified by Georgia Lainiotis.

This is a portfolio project. It is not affiliated with or endorsed by Have I Been Pwned or its creator.

## What's included

- **Getting Started guide:** takes a new developer to a working request in about five minutes, with no setup.
- **API reference:** authentication, error handling, and three endpoints (Get a Single Breach, Get All Data Classes, and the Pwned Passwords range check).
- **Changelog:** version history for the documentation itself.

## How it was verified

Every example was tested against the live API. Where the vendor's published documentation differs from what the API actually returns, the difference is noted on the relevant page.
